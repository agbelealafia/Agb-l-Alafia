🌿 Administration — Agbélé-Alafia

Modifiez le contenu de votre site

Cette page vous permet de changer tous les textes, numéros et liens du site sans jamais toucher au code. Vous modifiez ici, vous téléchargez un fichier, vous le déposez sur GitHub à la place de l'ancien — et le changement apparaît aussitôt chez tous vos visiteurs, sur tous les appareils.

  1. 1Cliquez sur « Charger mon data.json » et sélectionnez le fichier data.json actuellement sur votre GitHub (pour partir de ce qui est déjà en ligne).
  2. 2Modifiez les champs ci-dessous. L'aperçu à droite se met à jour instantanément.
  3. 3Cliquez sur « Télécharger data.json ». Le fichier est enregistré dans votre dossier Téléchargements.
  4. 4Sur GitHub, ouvrez votre dépôt → cliquez sur data.json → icône crayon (Edit) ou « Add file > Upload files » → déposez le nouveau fichier → « Commit changes ».
✅ data.json téléchargé ! Il ne vous reste qu'à le déposer sur GitHub à la place de l'ancien.
